# Frontend Architecture — Project Atlas

## Overview

Project Atlas does not have a graphical user interface or web frontend in the initial scope. The primary interface is:

1. **CLI (command-line interface)** — planned for D-05, for running research cycles and managing agents.
2. **Documentation (Markdown)** — the knowledge base and management docs serve as the primary user interface for understanding the project.
3. **Git** — branches, worktrees, commits, and merges are the operational interface.

## Future frontend considerations (not in scope)

If a frontend is added later, it would likely be:
- A lightweight web UI for viewing research reports and knowledge base
- A CLI for submitting objectives and viewing agent status
- Integration with MCP for tool access

These are explicitly out of scope for the initial implementation per the goals-and-scope.md (F-09, F-11 are low priority).
