# Glossary — Project Atlas

| Term | Definition | Context |
|------|------------|---------|
| Orchestrator | The coordinating agent that decomposes tasks, delegates to workers, and synthesizes results | Multi-agent systems |
| Worker / Subagent | A specialized agent assigned to an independent task with bounded context | Multi-agent systems |
| Git worktree | A separate working directory checked out from the same repository on its own branch | Git version control |
| Branch | A separate line of Git development isolating one set of changes | Git version control |
| Main branch | The primary branch containing approved, integrated work | Git version control |
| Research cycle | A repeatable process: plan → delegate → investigate → report → review → synthesize → commit → reassess | Project methodology |
| Knowledge base | Centralized, structured documentation of concepts, technologies, patterns, use cases, papers | Project documentation |
| FACT | A claim supported by credible evidence with a source link | Evidence standard |
| INTERPRETATION | A conclusion derived from evidence | Evidence standard |
| HYPOTHESIS | An idea requiring validation | Evidence standard |
| PROPOSAL | A suggested direction for the project | Evidence standard |
| Orchestrator-worker pattern | A lead agent delegates to parallel workers and synthesizes results | Multi-agent architecture |
| LangGraph | A graph-based orchestration framework for LLM agents | Technology |
| MCP | Model Context Protocol — standard for connecting LLMs to tools and data | Technology |
| A2A | Agent-to-Agent protocol — standardized inter-agent communication | Technology |
| LLM-as-judge | Using an LLM to evaluate the quality of another LLM's output | Evaluation |
| Human-in-the-loop | A human reviews and approves agent output before integration | Governance |
