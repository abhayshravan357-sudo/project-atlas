# User Stories — Project Atlas

| ID | User story | Priority |
|----|------------|----------|
| US-01 | As a project owner, I want to understand what technologies could support my project so that I can make an informed stack decision | High |
| US-02 | As a project owner, I want to compare architecture alternatives (orchestrator-worker, sequential, hierarchical, peer-to-peer) so that I can choose the best fit | High |
| US-03 | As a project owner, I want to see the evidence behind each technology and architecture decision so that I can trust and revisit those decisions | High |
| US-04 | As a new team member, I want to read the documentation and understand how the system works without guessing | High |
| US-05 | As a developer, I want to know which files to modify when adding a feature and how to update the corresponding documentation | Medium |
| US-06 | As a project owner, I want to understand the cost and feasibility of running multi-agent research cycles so that I can budget appropriately | Medium |
| US-07 | As a reviewer, I want a clear rubric for evaluating research-report quality so that my reviews are consistent | Medium |
| US-08 | As a project owner, I want to know what Atlas will NOT do so that I have realistic expectations | Medium |
